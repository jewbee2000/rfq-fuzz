# T02 independent exported-artifact validator

Requirements: R03 (first-family M0 subset), R04 and R08; contributes focused controls for R17. This document and validator implementation are authored in a separate local worktree from the generator. The coordinator integrates sequentially and records the completion commit in tasks.json.

API: `inspect_case(folder, outdir, attestation=None)` and `validate_suite(public_root, outdir, attestation=None)`. They write private inspection/oracle JSON and retained rendered evidence. Valid scoring requires a hash-bound visual attestation. Without it a successfully measured case is `pending_visual_attestation`, with no `expected_conclusion`. Corrupt fixtures are `invalid_fixture`; unknown schema versions are `unsupported`. No result in those states is a pass.

STEP is reopened directly with OCP.STEPControl_Reader. No generator object, sidecar or generator import supplies measurements. Checks cover actual ISO-10303-21 signature/end marker, OCCT FileUnits and SI declaration, one transferred root/solid, BRep validity, exact envelope and center, six plane faces/four complete cylindrical walls, four XY associations, radius, Z axis, through depth, surface area and independent analytic volume. Actual final geometry: envelope 80 x 50 x 8 mm, Z [-4,4], four radius-3 bores at (-25,-15), (-25,15), (25,-15), (25,15). Measured volume 31095.22131576612 mm3 versus analytic 31095.22131576614 mm3; error -1.82e-11. Length tolerance remains 1e-6 mm; volume tolerance 1e-5 mm3.

Drawing text and positions come from pypdf on the exported PDF. Independent PDFium rerenders are compared with the shipped Poppler PNG at 200 DPI, using binary ink with a 2-pixel dilation to accommodate edge antialiasing; maximum unmatched ratio 0.015 is an explicit engineering visibility heuristic. No dimension is measured from pixel scale. Per-label crops, ink counts, callout crop and full reread raster are retained. The exported text contains real Unicode multiplication ×, diameter ø and plus-minus ±; earlier terminal replacement glyphs were Windows console encoding, not PDF decode failure.

Draftwright visibly centers notes in their table while its hidden search text X coordinate is at the left origin. Therefore those labels are associated with complete row-interior crops, rather than claiming search coordinates locate visible glyphs. Table border rules are excluded from their ink signal. Ink cannot prove that the visible text equals searchable text; coordinated visual inspection of all three hash-bound PDFs/PNGs remains obligatory. The attestation checks callout count/numeric values/symbols, stage/ream context, explicit supplied-model-view stage, envelopes and legibility. Raster whiteout tests prove searchable text alone cannot bypass the oracle.

The three-case suite requires identical measured geometry; two same-stage cases and one explicit intermediate-to-finished H1 ream transition; one observed contradiction and two finite supported-clear conclusions. Same-stage tokens may change only the nominal bore annotation. Valid-alternative versus defective tokens may change only exact stage and operation notes. Other public engineering premises remain invariant. Nonsemantic drawing layout reflow is permitted; dimensions still come from labels/STEP. A stage-qualified supported-clear is package consistency only, not process feasibility or manufacturing approval.

Acceptance run in the validator worktree, using the repository's pinned Python 3.12 venv and final root artifacts:

```powershell
../../.venv/Scripts/python.exe -m pytest tests/m0/test_validation.py --basetemp evidence/M0/tmp-negatives -q
```

Initial focused run: 10 passed in 9.30 s; final expanded run: 11 passed in 9.23 s. Controls retain corrupted/truncated STEP; actual STEP metre units with millimetre packet; independently authored three-bore OCCT solid; unmanifested hash mutation; searchable callout whiteout with PNG regenerated from the changed PDF; searchable model-stage note whiteout preserving table; a rehashed white PNG; missing/stale visual attestation; and a distinct unsupported-schema control. Two pypdf deprecation warnings from test-only overlay construction were repaired by attaching the source page to a writer before merging. The coordinator's combined root run should use `--basetemp evidence/M0/negative-tests` to retain mutation packets, input artifacts and inspection JSON in committed evidence.

Failed implementation observations before the passing checks: initial assumption that Z lay [0,8] was disproved by actual STEP [-4,4] (the frozen contract specified depth8, not origin); initial point-level note ink region was disproved by actual raster centering; the bore parser initially allowed uppercase diameter Ø but actual PDF encoded lowercase ø. These are recorded design corrections, not relaxed engineering tolerances. No generated fixture was accepted merely because generator metadata said it was valid.

Limits: same OCCT kernel in generator and validator is a common-mode risk; closed-form volume/topology checks supplement rather than eliminate it. PDF ink matching is a finite curated visibility signal. Parser process timeouts/adversarial containment and arbitrary uploaded drawing interpretation are not established by this M0 module. Same-user worktree independence is organizational, not secure isolation. T02 remains worthwhile for this explicitly synthetic first-family consistency proof; broader oracle generality and industrial transfer remain later gates.
