# Evidence

This repository currently contains a researched plan only. No application tests, manufacturing trials or reviewer benchmark runs have been performed for RFQFuzz.

Implementation tasks name their future evidence paths in tasks.json. Retain commands, versions, input hashes, actual outputs, exclusions and decisions. A passing task requires evidence, not a changed status label. Generated private engineering data and credentials must not be committed by default.

PLAN_AUDIT.json, when present, verifies only planning-document structure and consistency. It is not application or engineering validation.
